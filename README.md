# NUIT

Сайт NUIT с закрытой админ-панелью для управления товарами и фотографиями.

## Что умеет админка

- Вход только по одному заданному email и паролю.
- Создание, редактирование, публикация, скрытие и удаление товаров.
- Загрузка нескольких фотографий JPEG, PNG или WebP до 12 МБ.
- Поля товара: название, цена, цвет, состав, плотность, описание и статус.

Админка доступна по `/admin` и не показана в публичной навигации. Проверка прав происходит на сервере для каждого API-запроса.

## Первый запуск на сервере

Нужны Docker и Docker Compose.

```bash
cp .env.example .env
npm run create-password-hash -- 'придумайте-длинный-пароль'
```

Скопируйте выведенный хеш в `ADMIN_PASSWORD_HASH` файла `.env`. Задайте также email клиента, одинаковый пароль PostgreSQL в `POSTGRES_PASSWORD` и `DATABASE_URL`, а для `AUTH_SECRET` используйте случайную строку не короче 32 символов.

```bash
docker compose up -d --build
```

Сайт будет работать на порту `3000`. Подключите домен через Caddy или Nginx с HTTPS и проксированием на `http://127.0.0.1:3000`.

## Резервные копии

Товары хранятся в Docker-volume `postgres`, а загруженные фото — в `uploads`. Их нужно включить в резервное копирование сервера.
